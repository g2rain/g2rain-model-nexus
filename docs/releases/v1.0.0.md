# g2rain-model-nexus v1.0.0

## 定位与交付内容

`g2rain-model-nexus` 是 G2rain（谷雨）开源智能体平台中的模型访问服务，并非完整平台发行版。它交付模型服务目录与接入资料管理、模型用量记录，以及 OpenAI 风格聊天和 Embeddings 请求到 OpenAI、Anthropic 或 Google GenAI 客户端的协议路由与转换。Agent 的任务编排由 Agent Runtime 负责，Agent/Skill 配置由 Agent Studio 负责，MCP 工具目录由 MCP Registry 负责；身份权限、网关、部署编排、知识库、SaaS 基座和商业化能力也不由本镜像单独提供。

平台已具备应用开发与部署能力；智能体平台与智能客服已开发完成并开源，交易开通、计量计费等商业化能力仍处于规划设计中。在线演示、某个环境已部署以及本组件镜像已发布是彼此独立的状态：本说明不宣称 v1.0.0 已完成在线演示或任何实际环境部署验证。

## 版本、构建与运行要求

- 项目版本事实源：根 `pom.xml` 的 `<revision>`，本版为 `1.0.0`；三个 Maven 模块均继承该版本。
- 构建：JDK 25、Maven；执行 `mvn clean verify` 可运行本仓库 Maven 验证生命周期和测试。`./build.sh 1.0.0` 会执行 `mvn clean install`（包含测试）后调用 Jib，将镜像载入本地 Docker，因此还需要可用的 Docker daemon。
- 关键框架：Spring Boot `4.1.2`、Spring Cloud `2025.1.4`、Spring AI `2.0.2`；容器基础镜像为 `eclipse-temurin:25.0.4.1_1-jre`。
- 运行：入口类为 `com.g2rain.model.nexus.Application`，声明端口 `8080`，可用 `SERVER_PORT` 覆盖；默认 profile 为 `nacos`。实际运行还依赖 MySQL、Redis、Nacos 与已授权的模型供应商服务。

## GHCR 镜像与发布顺序

- 镜像地址：`ghcr.io/g2rain/g2rain-model-nexus`。
- 当 `main` 中的提交创建并推送精确 `v1.0.0` 形式的稳定版 Git tag 时，工作流先验证 tag、`origin/main` 祖先关系、本说明文件和 Maven 项目版本，随后完整构建与测试，再用 Jib 推送 `1.0.0` 和 `sha-<完整 Git 提交 SHA>` 两个标签。
- 不创建 GitHub Release、不部署服务、不更新或推送 `latest`。本地镜像、CI 构建、推送镜像共用同一 Jib 配置、基础镜像、入口、端口和 OCI 元数据。
- OCI 标签包括 source（本仓库 URL）、Apache-2.0 license、title 和 Maven project version。

发布改动、工作流和本说明必须先合入 `main`；完成 CI 验证后，维护者再在该提交创建并推送 `v1.0.0` tag。GitHub Actions 的 Summary 仅在 Jib 已成功推送两个标签后报告完整镜像地址。

## 镜像内容与安全

Jib 从 Spring Boot 启动模块生成镜像，包含启动模块的编译类、依赖层和打包 resources；业务模块中的 MyBatis mapper XML 会作为 classpath 资源随依赖 JAR 进入镜像。它不使用 Dockerfile 或 `.dockerignore`。

已跟踪的 `g2rain-model-nexus-startup/src/main/resources/application-dev.yml` 含本地 MySQL 默认凭据，`application-nacos.yml` 含 Nacos 默认凭据。这些资源会随应用 JAR 进入最终镜像。维护者必须在发布前评估并轮换这些值；生产环境只能通过平台 Secret、环境变量或受控 Nacos 配置注入生产凭据、服务地址和模型供应商密钥，不能依赖或复用镜像内默认值。本发布变更不会删除文件或改写 Git 历史。

## 权限、拉取与限制

首次成功推送后，请在 GitHub Packages 的 **Package settings → Change visibility → Public** 将包设为公开；若组织管理员禁止此操作，请联系组织管理员。已有 GHCR 包还可能需要在 **Package settings → Actions access** 中授予 `g2rain/g2rain-model-nexus` 写权限。若推送得到 `denied`，先检查该设置和组织的 Packages 策略，不能仅凭 `packages: write` 判断权限已足够。

公开后可匿名拉取，例如 `docker pull ghcr.io/g2rain/g2rain-model-nexus:1.0.0`。匿名拉取只验证包可见性，不验证服务已配置、已启动或对外可用。镜像发布也不替代针对 MySQL、Redis、Nacos、模型供应商、Gateway 和生产权限策略的实际部署验证。
